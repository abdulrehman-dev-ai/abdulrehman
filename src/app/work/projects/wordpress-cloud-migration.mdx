## Challenge

A client site required infrastructure migration and recovery from WordPress administration and proxy-routing issues.

## Solution

- Diagnosed administrator lockout and Cloudflare redirect problems.
- Migrated the application to a Vultr-based Linux environment.
- Configured Nginx, MariaDB, PHP and HTTPS with Certbot.
- Used WP-CLI to update application URLs after migration.
- Verified mobile usability and post-migration website behavior.

## Result

Completed client infrastructure recovery and website restoration. Private customer details and server credentials are omitted.
